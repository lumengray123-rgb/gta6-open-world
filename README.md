SOLMARA — Streets of Solmara: a low-poly 3D open-world crime game in a sun-soaked coastal city, built with three.js. Explore an 8×8 road-grid city on foot and by car, steal cars, outrun police with a 0–5 star wanted system, take on 6 story missions from fixer Vera Solano, fight rival gangs, and save your progress. Fully offline — static files only, no network requests.

## Run it

```sh
cd game && python3 -m http.server 8000
# then open http://localhost:8000 in desktop Chrome
```
